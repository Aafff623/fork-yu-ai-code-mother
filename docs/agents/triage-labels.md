# Triage Labels

五种 canonical 角色 ↔ 本仓本地 Issue 的 `Status:` 字符串（一一对应）。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage`             | `needs-triage`       | 维护者需评估 |
| `needs-info`               | `needs-info`         | 等待报告人补充 |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可 AFK Agent 接手 |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现 |
| `wontfix`                  | `wontfix`            | 不做 |

Skill 提到角色时，使用上表右侧字符串。
